# Security Policy

## Scope

This repository distributes publication metadata and release assets. It does not contain an executable application or production service.

Security reports are appropriate when they concern:

- an unexpected or unauthorised change to a publication file;
- a malicious or misleading download link;
- suspected credential, token or personal-data exposure;
- repository impersonation or supply-chain tampering.

Editorial corrections, citation questions and ordinary content issues may be reported through a public GitHub issue.

## Private reporting

Please use [GitHub private vulnerability reporting](https://github.com/nobelJackal/NOMOS-GEO-Audit-Protocol/security/advisories/new) for sensitive reports. Do not post suspected credentials, personal data or exploit details in a public issue.

Include the affected URL, file or commit; the observed behaviour; steps to reproduce where relevant; and only redacted supporting material. Never send passwords, access tokens, session cookies, recovery codes or private keys.

## Supported publication

| Version | Supported |
|---|---|
| 0.9.x editorial edition | Yes |
| Earlier versions | No |

Reports are reviewed on a best-effort basis. Receipt does not confirm a vulnerability, and no fixed response-time guarantee is made.
