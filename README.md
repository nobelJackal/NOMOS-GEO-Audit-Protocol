# NOMOS GEO Audit Protocol v0.9.0

[![English edition DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22040507.svg)](https://doi.org/10.5281/zenodo.22040507)
[![ORCID](https://img.shields.io/badge/ORCID-0009--0000--2277--9009-a6ce39)](https://orcid.org/0009-0000-2277-9009)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

A publisher-authored proposed audit protocol for evaluating how entities are represented in generative search and answer systems. Version 0.9.0 is an editorial edition available in six languages.

> **Status:** NOMOS is a work in progress developed within NobleJackal. It is not an officially adopted industry standard, accreditation, certification or independent validation, and it does not guarantee rankings, visibility or citations.

## What the editorial edition introduces

The publication describes the GEO-1000 method, a canonical question registry, truth packs, evidence requirements, scoring logic, correction steps and revalidation records.
